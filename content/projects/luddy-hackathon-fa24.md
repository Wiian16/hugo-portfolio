In November of 2024, I competed in the second edition of the 
[Luddy Hackathon](https://luddy.indiana.edu/student-life/hackathon.html). This was the second time working with my team
of Lillie Donato, Sam Miller, and Matthew Widjaja. 

The case we chose involved creating an API to assist employees in a company find points of contact for projects or
repositories. Our solution to this prompt was 
[Contact Point](https://github.com/ArchBTW-LuddyHackathonTeam/LuddyHackathonFA24). Contact Point is a RESTful API that
can connect users to relevant people for a given project. 

The app includes the following features: 
- A well documented RESTful API via the OpenAPI spec
- Secure session handling with JWT tokens
- An intuitive frontend designed with ReactJS
- Fuzzy finding endpoint with filters for faster search
- Authenticated users and protected routes
- A PostgresQL database
- Containerized backend and fronted server using Docker

My role in this project primarily dealt with backend infrastructure including database interfaces, api routes, fuzzy 
searching, OpenAPI documentation, and containerization using Docker. This was yet another incredible learning 
experience and my first experience with large TypeScript codebases. 

While I am proud of my work and what I learned during this experience, there are not currently any plans to continue
development of this project.
